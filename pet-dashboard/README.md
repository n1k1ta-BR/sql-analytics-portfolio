# Commerce Lab — SQL Dashboard

Интерактивный дашборд по семи задачам первого SQL-проекта. Стек: **Streamlit, Plotly, SQLite, pandas**.

## Разделы

- **Продажи:** выручка, заказы, средний чек, динамика по месяцам, топ-3 товара, промокоды.
- **Пользователи:** LTV-сегменты, повторные покупки по городам, активация по каналам.
- **Возможности роста:** категории с просмотрами без покупок, аномально крупные заказы.

Есть фильтры, экспорт таблиц в CSV и просмотр SQL. Готовые синтетические данные включены — подключать внешнюю базу не нужно.

## Добавление в общий репозиторий

Положите папку `dashboard/` рядом с `ecommerce-analytics/` и `query-optimization/`. Имена соседних папок не влияют на запуск.

В общий README можно добавить ссылку на `dashboard/README.md`.

## Запуск

Python 3.11+. Из корня общего репозитория:

```bash
python -m venv .venv
```

Активируйте окружение:

- macOS / Linux: `source .venv/bin/activate`
- Windows PowerShell: `.venv\Scripts\Activate.ps1`

```bash
python -m pip install -r dashboard/requirements.txt
python -m streamlit run dashboard/app.py
```

Откройте `http://localhost:8501`. На macOS, если команда `python` недоступна, используйте `python3` для создания окружения.

## Данные и расчёты

В `data/` лежат пять CSV из первого проекта (seed 42): 700 пользователей, 80 товаров, 2 600 заказов, 6 481 позиция и 9 499 событий. SQLite создаётся в памяти; все показатели рассчитываются SQL-запросами из `sql/`.

Канал привлечения фильтрует все разделы. Период заказов действует только на «Продажи». LTV, повторные покупки, активация и аномалии используют полную доступную историю. Деньги указаны в условных единицах.

Подробные определения и соответствие семи задачам: [METRICS.md](METRICS.md).

## Проверка

```bash
python -m unittest discover -s dashboard/tests -v
```

Проверяются расчёты, границы дат, равенство выручки, навигация, каналы и пустой период. Семь метрик сверены с автопроверкой исходного проекта. Интерфейс проверен через Streamlit AppTest; визуальная проверка в браузере в среде сборки недоступна.

Чтобы заново сгенерировать CSV: `python dashboard/export_demo_data.py`. После изменения CSV перезапустите приложение для сброса кэша.
