# SQL E-commerce Analytics

Учебный pet-проект по анализу данных интернет-магазина: 7 задач на SQL с использованием подзапросов, CTE, группировок и оконных функций.

**Стек:** SQLite, Python, pandas, NumPy.

## Задачи

1. Сегментация пользователей по LTV и количеству оплаченных заказов.
2. Топ-3 товара в каждой категории по месячной выручке.
3. Поиск категорий, которые пользователь просматривал, но не покупал.
4. Анализ промокодов: количество заказов, выручка и средний чек.
5. Поиск городов с долей повторных покупателей выше общей.
6. Расчёт активации пользователей в первые 7 дней по каналам привлечения.
7. Поиск заказов, сумма которых более чем втрое превышает среднюю сумму предыдущих заказов пользователя.

## Структура

- `sql/` — SQL-решения.
- `scripts/` — генерация данных, запуск запросов и проверка результатов.
- `notebooks/` — ноутбуки с решениями.
- `docs/tasks.md` — условия задач.
- `results/` — результаты запросов в CSV.

## Запуск

Требуется Python 3.11+. Выполните из корня проекта:

```bash
python -m pip install -r requirements.txt
python scripts/generate_data.py
python scripts/run_queries.py
```

Запуск отдельной задачи:

```bash
python scripts/run_queries.py --task 2
```

Проверка решений:

```bash
python scripts/validate.py
```

Также можно открыть `notebooks/solutions.ipynb` в Google Colab и выполнить ячейки по порядку.

## Данные

Используются синтетические данные интернет-магазина: пользователи, товары, заказы, позиции заказов и события. База SQLite создаётся генератором локально.
