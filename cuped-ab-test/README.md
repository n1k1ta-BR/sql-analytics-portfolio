# CUPED в A/B-тесте

Пример применения CUPED на синтетических данных. Сравниваю разность средних
между тестовой и контрольной группами до и после поправки на метрику,
измеренную до эксперимента.

## Что в ноутбуке

- Генерация данных для двух групп по 8 000 пользователей.
- Расчёт коэффициента CUPED через ковариацию и дисперсию.
- Сравнение оценок эффекта, стандартных ошибок и 95%-х доверительных интервалов.
- Разбор того, почему метрика, которая зависит от воздействия, не подходит для поправки.
- Оценка снижения дисперсии через квадрат корреляции.

## Результат

| Метод | Оценка эффекта | Стандартная ошибка | 95%-й доверительный интервал |
|---|---:|---:|---:|
| Исходная метрика | 0,3001 | 0,0892 | [0,1253; 0,4748] |
| CUPED | 0,2556 | 0,0552 | [0,1474; 0,3637] |

CUPED снизил стандартную ошибку на 38,1%. Истинный эффект, заданный
в генераторе данных, равен 0,25 единицы метрики.

## Как запустить

Откройте [cuped_ab_test.ipynb](cuped_ab_test.ipynb) в Google Colab и выполните все
ячейки. Данные генерируются в первой кодовой ячейке.

Для локального запуска установите зависимости в окружении Python 3.12.

```bash
python -m pip install -r requirements.txt
python -m pip install jupyterlab
jupyter lab cuped_ab_test.ipynb
```
